DIVYA & ASHWIN — WEDDING INVITATION WEBSITE

OPEN
- Open index.html in a modern browser to preview locally.
- Keep the assets folder beside index.html.

EDIT
- Main text and event information are in index.html.
- Search for the CONFIG object near the bottom of the page to edit the couple name, date/time, venue and map URL.
- Replace the JPGs in assets/ with your own images, keeping the same filenames, or update the image src paths in index.html.
- The date shown in the scratch card is in the HTML. Update it separately if you change the date.
- Background music: add a licensed MP3 you own or have permission to use as assets/music.mp3. Mobile browsers require a user tap to start playback.
- For WhatsApp/social preview, the page uses the public cover image URL. Social apps need a public HTTPS URL to fetch the preview.

GITHUB PAGES
- In the repository, open Settings > Pages.
- Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
- Once the site files and assets are in place and Pages finishes deploying, the invitation URL will be:
  https://divyzz.github.io/divya-ashwin-wedding/
